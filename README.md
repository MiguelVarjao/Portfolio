# Portfólio React

Portfólio de uma página inspirado nas referências enviadas.

## Tecnologias

- React
- Vite
- CSS

## Como executar

```bash
npm install
npm run dev
```

Depois abra o endereço mostrado pelo Vite.

## Estrutura

- `src/App.jsx` — conteúdo da página
- `src/components/Navbar.jsx` — Navbar
- `src/styles.css` — todo o estilo

A navegação usa âncoras HTML (`href="#sobre"`) e `id`, portanto não usa React Router e continua na mesma página.
